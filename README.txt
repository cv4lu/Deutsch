DEUTSCH TRAINER NIGHT — Verben & Präpositionen

Новая версия приложения с тёмной темой и мягкими анимациями.
Внутри: карточки, тест выбора предлогов, словарь, фильтры Dativ/Akkusativ и ошибки.
Прогресс сохраняется локально в браузере этого устройства.

Локальный запуск:
Открой index.html в браузере/HTML-просмотрщике с поддержкой JavaScript.

Установка как веб-приложения на iPhone:
Для добавления на экран «Домой» через Safari приложение должно быть опубликовано по HTTPS.
Файлы: index.html, manifest.json, sw.js.
